# gist — 和你的 AI Agent 一起从视频中学

```
你扔链接 → AI 快速提取精华 → 你们一起讨论 → 学到东西
```

不是"视频转文字工具"，是**你和 AI 一起成长的学习引擎**。

## 它能做什么

你每天刷到大量优质视频——B站的深度教程、抖音的干货分享、YouTube 的演讲访谈……

但你没时间看完，或者看完就忘，更别说把里面的经验真正用起来。

**gist 就是解决这个问题的：**

```
一条命令，把视频里的方法论拆给你：
  🧠 思维模型 — 视频里用了什么思考框架？
  📏 原则规则 — 能直接用的判断标准？
  📖 案例经验 — 实际怎么操作的？
  💡 可执行步骤 — 我能照着做什么？
  ⚠️ 边界注意 — 哪里容易翻车？
```

然后你和 AI 一起分析、讨论、复用——把别人的经验变成你的能力。

## 一条命令

```bash
python gist.py <B站/抖音/YouTube/任何视频链接>
```

## 支持哪些平台

1200+ 平台，一条命令全支持。

**国内**：B站、抖音、快手、小红书、微博、优酷、爱奇艺、腾讯视频……

**国外**：YouTube、Netflix、TikTok、Instagram、Twitter/X、Vimeo……

## 快速开始

```bash
pip install yt-dlp openai-whisper torch
python gist.py https://www.bilibili.com/video/BVxxx
```

## 理念

不是"看完"，是**学完**。不是"收藏"，是**复用**。

```
链接 → 提取 → 讨论 → 内化 → 复用
```

这是你和 AI Agent 一起从优质视频中持续学习的闭环。
